# pairwise-race-guard

优惠券领完即止的接口一上并发，超卖和重复领取就一起出现：先查余量再扣减，两个请求都读到 1；扣减没有原子条件，余量能变负；同一用户并发领多张；请求重试没有幂等键；分布式锁只锁单机；事务隔离级别不够，读到旧值；扣减成功但发券失败，余量白扣；失败重试把已成功当失败；缓存余量和数据库不一致；批量领取循环里没有统一事务。security/race_guard.py 是核心，tests/test_race_guard.py 15个红。要修的是：条件更新；余量非负约束；用户唯一约束；幂等键；跨实例锁；事务隔离；扣减与发券同事务；重试查结果；缓存以库为准；批量统一事务。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：漏洞检测与攻防；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
